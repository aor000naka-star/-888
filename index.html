ความหมาย สมบัติ & กราฟสมการ

🦉
ฮูกน้อยผู้รอบรู้ยินดีต้อนรับ! มาเรียนรู้ความหมายและสมบัติของสมการกันเถอะ ฮูก! 📚✨

1. ความหมายและรูปทั่วไป

สมการเชิงเส้นตัวแปรเดียว คือ ประโยคสัญลักษณ์ที่มีเครื่องหมายเท่ากับ (=) มีตัวแปรเพียง 1 ตัว และตัวแปรนั้นมีเลขชี้กำลังสูงสุดเท่ากับ 1 เสมอ

รูปทั่วไป: ax + b = 0 (เมื่อ a ≠ 0)

2. สมบัติของการเท่ากัน (เครื่องมือช่วยแก้สมการ)

เปรียบเสมือน "ตาชั่งสองแขน" ที่ต้องสมดุลกันเสมอ

  • สมบัติสมมาตร: สลับฝั่งซ้ายขวาได้ (a = b แล้ว b = a)
  • สมบัติถ่ายทอด: ถ้า a = b และ b = c แล้ว a = c
  • สมบัติการบวก: บวกหรือลบด้วยตัวเลขเดียวกันทั้งสองข้าง
  • สมบัติการคูณ: คูณหรือหารด้วยตัวเลขเดียวกันทั้งสองข้าง (ตัวหารต้องไม่เป็นศูนย์)

3. สื่อจำลองกราฟและขั้นตอนแก้สมการแบบ Real-time

2x - 4 = 0

กราฟเส้นตรง y = ax + b

🛍️ สถานการณ์ที่ 1: การซื้อของ

โจทย์: "ซื้อขนม 2 ห่อ จ่ายแบงก์ 50 บาท ได้เงินทอน 10 บาท ขนมราคาห่อละเท่าไร?"

สมการ: 2x + 10 = 50

💰 สถานการณ์ที่ 2: เงินสะสม

โจทย์: "ฉันมีเงินอยู่จำนวนหนึ่ง พ่อให้อีก 20 บาท ทำให้ฉันมีเงินรวม 100 บาท ฉันมีเงินตอนแรกกี่บาท?"

สมการ: x + 20 = 100
